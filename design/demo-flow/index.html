The demo, step by step

One continuous run on a real phone. There's no background agent for the demo: the agent starts as soon as onboarding finishes.

  1. Land on the homepage CTA not wired

    otherwise-homepage.vercel.app is live on Vercel. "Get started" has to link to the app's new phone-first entry, /start, on the Neon Function.

  2. Enter phone number missing

    Today a user can only start by messaging on WhatsApp. /start needs to take a phone number, create the user, mint the onboarding token and redirect to /onboard?t=…. Onboarding v2 also assumes WhatsApp comes first, so this step isn't in its plan yet.

  3. Onboarding: Berlin, swipe about 12 events, budget wt/onboarding

    The page is restyled to look like the homepage. The steps are city → starter-deck swipes → budget and auto-approve limit. Gmail/Calendar connect stays optional, and we skip it in the demo. The deck should include the Ticketeria mock events, so whatever the agent later books is something the user swiped right on.

  4. The agent says hi on WhatsApp, unprompted exists

    The onboard-user workflow builds the taste profile from the swipes, then notify-ready sends the intro. The Twilio sandbox only delivers if the phone has joined it and messaged within the last 24 hours (see Ops).

    Hey Philipp 👋 just finished setting you up. You're into jazz, indie film, late shows… I'll keep an eye out. 15:31

  5. Event search starts immediately glue

    Run discoverEvents once, right after notify-ready and inside the same waitUntil. No job queue or hourly tick (wt/background stays out).

  6. The agent picks a Ticketeria event and books it without asking glue

    Demo rule: the top mock-shop pick that fits the auto-approve limit goes straight to startBooking, skipping the 0.85 taste-confidence gate. The free Indie Film Club RSVP is the safe choice. A paid event of about €9 with the HACKATHON credits applied is more impressive, because it shows the total check and the card being filled in.

    Found something you'll like: Indie Film Club shorts, Thu 20:00. Booking it now. Watch me: otherwise…/bookings/abc/watch 15:33

  7. A Kernel browser checks out on Ticketeria wt/mock-booking

    The book-event steps: approve, hold, checkout sub-agent, verify total, pay with the env test card, settle. Committed on wt/mock-booking but not on main yet. The browser reaches the shop through PUBLIC_URL.

  8. Watch it happen new

    While the booking runs, a watch page embeds the Kernel live view (browser_live_view_url). Afterwards it plays the replay mp4 (browsers.replays.start/stop; headful only, which we already are; Kernel lists it as a paid feature).

  9. "I booked it" exists

    book.ts already sends this through tellUser. Add the replay link.

    ✅ Booked: 1× Indie Film Club shorts (Thu 20:00). Order TKT-4821. Free, nothing charged. Tickets: … Replay: … 15:36
